This MVC application was developed using a Node.js backend, MongoDB for data persistence, and a pure JavaScript frontend without the use of modern UI frameworks. MongoDB was leveraged to model and manage complex one-to-many relationships through both embedded and referenced documents, providing valuable experience in schema design and database architecture. One of the primary goals of this project was to strengthen and showcase this expertise by building the user interface/Project from the ground up. No ng new MyAngularApp, no npm create vue@latest, or any sort of scaffolding command. Just built out the file structure and typed away! By intentionally avoiding my go to frameworks such as Angular,Vue, or React, and more, I was able to focus on core JavaScript concepts, DOM manipulation with jquery, application state management, and custom component behavior without abstraction layers.. Like requested. Beyond the technical implementation, this project served as a realistic client-based development exercise. I was provided with business requirements, application specifications, data structure expectations, and functional objectives, simulating the experience of developing a solution for a real-world client. The result was a fully functioning application that demonstrates frontend development, backend architecture, database management, and the ability to translate business requirements into working software.

Axis & Allies Assistant is a companion application designed to enhance the classic Axis & Allies board game experience, not replace it. As a long-time fan of the game, I wanted to create a tool that simplifies gameplay by automating many of the tedious tasks players encounter throughout a match. Designed for both my gaming group and the wider Axis & Allies community.. and thanks to Analytics, that community ranges from the US to Europe -- The application helps manage territory ownership, track income and resources, enforce game rules, and reduce the overhead of manual bookkeeping. This allows players to focus more on strategy and gameplay rather than constantly referencing rule books and tracking game state. From a technical standpoint, the project presented several unique challenges, including interactive territory mapping, area-based territory selection, complex game-state management, and rule automation. While the concept may seem straightforward, creating an intuitive system capable of accurately managing the intricacies of the game required thoughtful architecture and extensive logic implementation whilst mission focus on User Experience and not the technical structure. Combined with a modern user interface and streamlined user experience, the result is a powerful companion tool that makes the game more accessible, efficient, and enjoyable for both new and veteran players.

ZILLA is a side-scrolling action game developed using the Phaser game engine. The project leverages real-time physics, particle effects, sprite sheet animations, collision detection, and custom game logic to create an engaging arcade-style experience. Players take control of Godzilla in an alternate timeline where King Ghidorah has unleashed an army of clones upon Earth. Battling through the stratosphere, players must survive waves of enemies while navigating fast-paced gameplay and visual effects designed to capture the scale and intensity of kaiju combat. From a development perspective, this project provided valuable experience in game architecture, animation systems, physics-based interactions, asset management, and gameplay design. It demonstrates my ability to combine technical implementation with creative storytelling to deliver a polished and entertaining user experience with original background music.
